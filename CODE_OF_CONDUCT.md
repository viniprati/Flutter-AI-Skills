# Código de conduta

Queremos um espaço técnico respeitoso para pessoas de diferentes experiências. Ao participar, trate os demais com respeito, critique decisões e código com evidências e evite ataques pessoais, assédio, discriminação, exposição de dados privados e conteúdo sexual indesejado.

Esse compromisso vale para issues, pull requests, discussões e outros espaços oficiais do projeto. Mantenedores podem editar ou remover conteúdo inadequado e restringir a participação em casos graves ou repetidos.

Relate problemas de conduta de forma privada ao mantenedor por um canal informado no perfil do repositório. Inclua contexto suficiente para análise, sem publicar dados sensíveis. O mantenedor avaliará o relato com discrição e buscará resposta proporcional.
