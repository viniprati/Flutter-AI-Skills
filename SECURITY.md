# Política de segurança

Não abra uma issue pública com tokens, senhas, chaves, dados pessoais ou detalhes que facilitem exploração de um projeto. Envie uma descrição privada pelo recurso **Report a vulnerability** na aba Security do repositório GitHub, quando disponível. Se esse recurso não estiver habilitado, contate o mantenedor por um canal privado informado no perfil do repositório, sem anexar credenciais reais.

Inclua a skill ou o arquivo afetado, cenário de reprodução com dados fictícios, impacto e proposta de correção. Não teste exploração contra serviços ou dados de terceiros. O mantenedor triageará o relato e coordenará correção e divulgação; este projeto ainda não promete um prazo de resposta.

As skills são instruções. Antes de executar comandos ou copiar exemplos em um aplicativo, revise o contexto, dependências, permissões, tratamento de segredos e o efeito sobre dados reais.
